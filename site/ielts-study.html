本机运行的雅思学习工作台

把任何英文视频，变成一节雅思课。

粘贴 YouTube、Bilibili 或 TED 链接，几分钟后得到双语字幕：每个短语的中文就写在它下面，读到哪个词就亮哪个词。重点短语、雅思难词和听写练习一起生成。

三个模块

听力、单词、阅读，
用同一个词本串起来。

在视频和文章里点到的生词都进同一个收藏词句，带着原句和翻译；听写没过关的句子自动进错句本。左上角的首页会告诉你今天听写了几句、收藏了几个词、还有几句待重练。

听力 Listening

导入视频后，在播放器里跟读、查词、听写。

  • 英文按单词和短语分段，中文写在对应短语的正下方
  • 正在说的单词高亮，可选淡绿、淡黄、淡蓝
  • 单句循环、自动暂停、0.6× 到 1.5× 变速
  • 按 D 进入听写：边听边打，按词对比打分
  • 平台有字幕就用平台字幕，没有就在本机用 Whisper 转写

单词 Vocabulary

每个收藏都带着你遇到它的那句话。

  • 点任意单词查 ECDICT 离线词典，约 77 万词条
  • 重点短语来自约 230 条精选口语表达和词典短语
  • 点「原句」跳回视频的那一秒或文章的那一句
  • 一键导出 CSV，可导入 Anki

阅读 Reading

粘贴雅思阅读、新闻或范文，逐句精读。

  • 自动拆句、逐句翻译
  • 按你的目标分数标出难词
  • 点句末的「译」只看这一句的中文
  • 按 C 切换逐句中英对照

词汇分级

选你的目标分数，
只标你还不会的词。

难词只从雅思词表里挑，再按词频排名过滤：目标越高，标出来的词越少、越难。换分数不用重新导入，所有视频和文章立刻更新。

词频排名取自 ECDICT。播放器里每句最多标 2 个，优先标最难的。

导入一个视频时

从链接到可以学，
一共五步。

进度条会显示每一步。中途失败的话，已经下载和转写的部分不会丢：比如 API 某一批翻译出错，就只把这一批改用本地翻译。

  1. 读取视频信息

    标题、时长、可用的清晰度和字幕。

  2. 下载视频

    用 yt-dlp，清晰度上限可以在设置里选，480p 到最高。

  3. 获取英文字幕

    有人工字幕就直接用；没有就用 Whisper 在本机识别，并记下每个词的时间。

  4. 翻译字幕

    本地离线翻译，或用你自己的 API Key，按短语对照翻译。

  5. 标注重点

    用 spaCy 分析句子，再查 ECDICT，找出短语动词、固定搭配和雅思难词。

数据都在本机

没有账号，
也不用上传你的视频。

IELTS Study 是一个只在你电脑上运行的小服务，用浏览器打开就能用。关掉它，你的资料还在原来的文件夹里。

视频和学习记录

视频、字幕、听写成绩和文章都存在项目文件夹里，备份时拷走这个文件夹就行。

library/ · articles/

可以完全离线

选「本地翻译」时，转写、翻译、查词都不联网。只有下载视频本身需要网络。

Whisper · Argos · ECDICT

API 由你决定

想要更好的翻译，可以接 DeepSeek、OpenAI 等服务商。只会把字幕文字发给你选的服务商，Key 只保存在本机。

开始使用

一条命令启动，
浏览器自动打开。

第一次启动会准备离线词典；第一次遇到没有字幕的视频时，会下载 Whisper 模型。之后都很快。

  • 系统macOS，Apple Silicon（M 系列芯片），Whisper 转写靠它加速
  • 需要安装uv（Python 项目管理工具），其余依赖会自动安装
  • 地址http://127.0.0.1:8765，只有本机能访问
在项目文件夹里启动
uv run ielts-study
做一个桌面图标，以后双击打开
bash assets/build_app.sh
停止或重启后台服务
# 更新代码后用 --restart
uv run ielts-study --stop
uv run ielts-study --restart
