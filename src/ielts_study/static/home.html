IELTS Study · 本机运行的雅思学习工作台

把任何英文视频，变成一节雅思课。

粘贴 YouTube、Bilibili 或 TED 链接，得到双语字幕：每个短语的中文就写在它下面，读到哪个词就亮哪个词。重点短语、雅思难词和听写练习一起生成。也可以粘贴英文文章逐句精读。

开始视频精听 → 文章精读

功能

听力、单词、阅读，
用同一个词本串起来。

在视频和文章里点到的生词都进同一个「收藏词句」，带着原句和翻译；听写没过关的句子自动进「错句本」。每个功能都在左侧栏里有自己的入口。

听力 Listening

导入视频后，在播放器里跟读、查词、听写。

  • 英文按单词和短语分段，中文写在对应短语的正下方
  • 正在说的单词高亮，可选淡绿、淡黄、淡蓝
  • 单句循环、自动暂停、0.6× 到 1.5× 变速
  • 按 D 进入听写：边听边打，按词对比打分
  • 平台有字幕就用平台字幕，没有就在本机用 Whisper 转写
视频精听错句本

单词 Vocabulary

每个收藏都带着你遇到它的那句话。

  • 单词复习：原句挖空，按遗忘规律安排下次出现的时间
  • 点任意单词查离线词典 ECDICT
  • 重点短语来自精选口语表达和词典短语
  • 点「原句」跳回视频的那一秒或文章的那一句
  • 一键导出 CSV，可导入 Anki

阅读 Reading

  • 自动拆句、逐句翻译
  • 按你的目标分数标出难词
  • 点句末的「译」只看这一句的中文
  • 按 C 切换逐句中英对照

导入一个视频时

从链接到可以学，
一共五步。

进度条会显示每一步。中途出错的话，已经下载和转写的部分不会丢：比如 API 某一批翻译失败，只把这一批改用本地翻译。

  1. 读取视频信息

    标题、时长、可用的清晰度和字幕。

  2. 下载视频

    用 yt-dlp 下载，清晰度上限在设置里选。

  3. 获取英文字幕

    有人工字幕就直接用；没有就用 Whisper 在本机识别，并记下每个词的时间。

  4. 翻译字幕

    本地离线翻译，或用你自己的 API Key 按短语对照翻译。

  5. 标注重点

    分析句子结构，查词典，找出短语动词、固定搭配和雅思难词。

数据都在本机

视频、字幕、听写成绩、文章和词本都存在项目文件夹里，没有账号，也不上传视频。

可以完全离线

选「本地翻译」时，转写、翻译、查词都不联网，只有下载视频需要网络。

翻译模型由你选
