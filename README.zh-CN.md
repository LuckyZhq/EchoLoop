# IELTS Study

用真实的视频和文章学英语、备考雅思，支持 16 种母语。粘贴 YouTube、Bilibili、TED 或播客链接，自动生成双语字幕：每个短语的译文写在它下面，读到哪个词亮哪个词；按你的水平标出重点短语和雅思难词，可以逐句听写、复习收藏的单词。全部在你自己的电脑上运行，不需要账号，也不上传视频。

[English README](README.md)

## 安装和启动

需要 [uv](https://docs.astral.sh/uv/)（会自动安装合适的 Python 和所有依赖）和 git。

**macOS / Linux**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
git clone https://github.com/<you>/IELTS-study.git
cd IELTS-study
uv run ielts-study
```

**Windows**（PowerShell）

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
git clone https://github.com/<you>/IELTS-study.git
cd IELTS-study
uv run ielts-study
```

浏览器会自动打开 http://127.0.0.1:8765 。第一次启动要安装依赖、下载离线词典（ECDICT，约 66 MB，会校验完整性），需要几分钟；之后几秒就能打开。

以后可以双击 `scripts/IELTS-Study.bat`（Windows）或运行 `scripts/start.sh`（macOS / Linux）启动。Mac 上运行 `zsh assets/build_app.sh` 会在桌面放一个 IELTS-study 图标，双击即可在后台启动并打开页面（不弹终端窗口），日志在 `data/server.log`。

退出后台服务：`uv run ielts-study --stop`。改了代码或更新后，页面顶部会提示「立即重启」，也可以运行 `uv run ielts-study --restart`。

把视频链接粘贴到「视频精听」的输入框（⌘V / Ctrl+V 会自动开始），处理完成后自动进入播放器。

## 它做了什么

| 步骤 | 工具（都在本机） |
|---|---|
| 下载视频 | yt-dlp（支持 YouTube、Bilibili、TED、X 等上千个网站） |
| 英文字幕 | 优先用平台自带的人工字幕；没有的话用 Whisper 识别：Apple 芯片的 Mac 用 mlx-whisper，Windows / Linux 用 faster-whisper，模型大小在设置里选，也可以改用云端识别（见下文）|
| 中文翻译 | Argos Translate 离线英译中，或使用自己配置的 API |
| 重点短语 | 约 230 条精选口语短语 + ECDICT 词典短语，spaCy 识别时态变化和拆开的短语动词（如 *pick it up*） |
| 难词 | ECDICT 的雅思词表 + 词频排名，按「我的目标」里的水平和目标筛选 |
| 释义 | ECDICT 开源英汉词典（77 万词条） |

## 页面

左上角「IELTS Study」打开首页：选择母语（下拉框可搜索），界面和翻译一起切换。具体功能都在左侧栏各自的按钮里：

- **听力**：视频精听（导入视频、资料库、播放器、听写）和错句本
- **我的目标**（侧边栏最上面的醒目卡片，显示目标分数、阶段和今天完成了几项）：学多少、考什么只在这一页定，一屏四块。**当前水平**：读 3 篇短文、点出不认识的词，再抽查几个没点的词，估算词汇量和大约的雅思分数（只按词汇量粗略换算），也可以直接选分数。**目标**：目标分数和考试日期。**当前阶段**：按现在的分数自动定为入门 / 基础 / 提升 / 冲刺，写明依据（例如「现在 5.5 分 → 提升阶段 · 距目标还差 1.5 分 · 离考试还剩 120 天」），可以手动改，改了标「手动」；每个阶段推荐播放速度和中文显示，可一键应用。**每日配额**：新词、精听、听写、精读的数量，默认按阶段推荐，填上考试日期后新词数按「还差多少词 ÷ 剩余天数」推荐（每天最多 40 个），每一项都可以单独改。今日复习、词书、今天的计划、视频和文章里标出的难词都从这里取数，所以数字处处一致。页面上还有今天的计划（随学习自动更新进度、连续学习天数）、词汇量曲线和最近 30 天的学习时间图。视频和文章里只标「比现在难、又不超出目标太多」的词；词卡上的「✓ 认识」让这个词不再出现，单词复习里记牢的词也会自动不标
- **单词**：侧边栏只有一个「单词」入口，页内四个标签。**今日复习**：卡片把原句里的词挖空，可以听视频原声、拼写检查，按「忘了 / 模糊 / 记得 / 很简单」安排下次出现的时间（简化版 SM-2，每天的新词数量跟着学习计划）；顶部一行写明今天的卡片从哪来：今日新词（词书 · 收藏）、复习旧词、词书还剩多少。任何卡片上都可以点「✓ 认识，不再复习」。**我的生词**：所有词，按状态（学习中 / 已掌握）和来源（视频、文章、哪本词书、标记认识）筛选，可导出 CSV。**句子收藏**：在播放器的逐句原文或文章里点句子旁边的「☆」收藏整句，不进复习。每个词只有一条记录（`library/words.json`），一个状态：在任何地方标为认识，播放器不再标它、复习不再出现、词书不再安排
- **词书**（「单词」里的一个标签）：高频核心词 3000、四级、六级、考研、雅思、托福（母语不是中文时只显示核心词、雅思、托福），词表来自 ECDICT 的考试标签。选一本后，每天的新词自动进入单词复习：第一次出现先问「认识吗」，认识的按 K 跳过、以后不再出现，不认识的看释义和例句后进入复习。例句优先用你自己视频和文章里的原句（带原声），没有的话用 API 生成一句并缓存。已经认识、正在学的词，以及比你测出的词汇量更常用的词，自动跳过
- **阅读**：文章精读。按等级分栏：四级、六级、雅思 5.5 / 6.5 / 7+（母语不是中文时只显示雅思），等级自己选。内置文章是参照各考试的话题、篇幅和难度原创的（没有照抄真题），每级 3 篇；「用 API 写一篇」可以按等级和话题再生成新的。第一次打开时翻译和标注，之后直接读。「我的文章」里可以粘贴自己的英文文章，逐句翻译，标出重点短语和难词；点单词查词、收藏，点句末的「译」看这一句的中文，「中文对照」（C 键）逐句显示中文

- **口语**：口语练习。「跟读打分」：听一句原句（你导入视频里的原声，或分级阅读句子的神经语音），跟着读，逐词显示识别结果，对比你和原句的语速，标出发音不清楚的词。「口语模考」：按雅思 Part 1、Part 2（1 分钟准备计时和题卡）、Part 3 出题，考官声音读题；录下回答后识别成文字，统计语速、停顿、口头禅；配置了 API 时按雅思口语四项估分，给出改错、更好的说法和参考回答。录音只在本机识别
- **写作**：作文默写。Task 2 议论文、Task 1 图表（柱状图、折线图、表格）和 G 类书信，限时、字数统计、草稿自动保存，也可以粘贴自己的题目。用你配置的 API 按雅思写作四项评分，逐句改错（在原文里标出），给出更好的用词，并按你的思路改写成 8 分范文。批改过的作文都会保存，方便对比进步。题目是参照真题题型原创的

「最近在看」可以点标题折叠，下次打开仍保持折叠。导入页的翻译模型菜单会列出每个已配置服务商的全部模型（例如 DeepSeek V4.1 Flash 和 V4 Pro）。

## 朗读声音

单词和例句用本机运行的神经语音模型 [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) 朗读，听起来接近真人录音：英式女声、英式男声（雅思），美式（四六级）。第一次朗读时从 Hugging Face 下载模型（约 165 MB，连不上会改用 hf-mirror.com，断线后会接着下载）；下载好之前，以及选澳式口音时，用电脑自带的语音。在 设置 → 模型与服务 → 朗读声音 里选声音和口音。

## 语言

只有一个语言选择：**母语**（首页，或 设置 → 外观与语言）。字幕、短语和单词释义翻译成这种语言，按钮、菜单和提示也用这种语言。可选简体中文、繁體中文（台灣）、Español、Português、Français、Deutsch、日本語、한국어、Tiếng Việt、Bahasa Indonesia、ไทย、Türkçe、Русский、العربية、हिन्दी，以及只看英英释义的 English。第一次打开（资料库还是空的）时按浏览器的语言自动选择。阿拉伯语界面从右往左排版，英文学习内容保持从左往右。

想让界面和母语不一样（例如母语是中文、但想用英文界面），打开「界面语言与母语不同」这个高级开关，再选界面语言。

| | 中文母语 | 其他母语 |
|---|---|---|
| 字幕翻译 | API 或离线 | API（任何语言，带短语对照）或离线 Argos（第一次用某种语言时下载模型） |
| 单词释义 | 离线英汉词典 ECDICT | 有 API：翻成母语并缓存（同一个词只翻一次）；没有 API：英文释义 |
| 逐词释义 | 有 | 由 API 的短语对照代替 |
| 考试标签 | 中考 / 高考 / 四六级 / 托福 / 雅思 | TOEFL / IELTS / GRE |

简体和繁体之间马上切换（繁体用 OpenCC 台湾用语转换）。换成其他语言时会提示一句：已有视频和文章的译文仍是旧语言，在播放器或文章里点「↻ 重新翻译」可逐个重译。

界面翻译表在 `src/ielts_study/i18n/<语言>.json`：英文是人工写的，其他 13 种语言由大模型（DeepSeek）从英文生成，欢迎修正。界面加了新文字后，用设置里的 API 补全（只翻缺的条目；缺的条目在那之前显示英文）：

```bash
uv run ielts-study --translate-ui es     # 一种语言
uv run ielts-study --translate-ui all    # 全部
```

## 播放器

- 浅蓝底 = 重点短语，橙色底加下划线 = 难词，点击看释义；**点击任意单词都能查词**
- 播放时正在读的单词会高亮（设置里可关）。本地语音识别的视频用真实的逐词时间；平台字幕按位置估算
- 英文下面显示什么，规则只有一条：**用 API 翻译**时，模型把每句切成单词和短语，给出它们在这句里的意思，显示在对应英文的正下方（短语下有一条细线标出范围），其余单词显示词典释义；**本地翻译**时只显示整句译文，点单词查词典（逐词的词典直译和整句意思常常对不上，所以不再并排显示）。鼠标停在英文下面的小字上，会显示它来自「短语对照：模型翻译」还是「单词释义：词典直译」；播放器顶部写明这次用的是哪种翻译。按 G 或在 设置 → 播放 里开关。正在读的单词用淡绿底标出（设置 → 播放里可改成淡黄、淡蓝）。已有视频可以在播放器里点「↻ 重新翻译」（只重新翻译，不重新下载）
- ☆ 收藏 → 进入「我的生词」并马上加入复习，保留原句和视频时间（可导出 CSV 给 Anki）；逐句原文里每句时间下面的 ☆ 收藏整句到「句子收藏」
- 单句循环、逐句暂停、0.6×–1.5× 变速、导出双语 / 英文 / 中文 SRT
- 快捷键：空格 播放/暂停，←/→ 上/下一句，↑ 重听，L 单句循环，P 逐句暂停，C 中文，M 标注，D 听写

## 听写

点「✎ 听写」或按 D。字幕会被模糊，每次只播放一句并自动暂停；把听到的内容写进输入框，按 Enter 检查。

- 逐词对比：拼写错（黄色波浪线）算半对，听错、漏听标红，多写的词单独列出
- 数字和英文数字（5 / five）、缩写（don't / do not）、英式和美式拼写（colour / color）都算对
- ↑ 重听，🐢 慢速 0.75× 重听，可以提示首字母或直接看答案（不记成绩）
- 成绩保存在 `library/<视频>/dictation.json`；低于 90% 的句子可以用「只练错句」专门重练
- 侧边栏「错句本」汇总所有视频里低于 90% 的句子（数字是待重练句数），直接在这一页放原声、听写、打分；也可以回到视频里把整个视频的错句一起重练；重练到 90% 以上自动移出
- 删除视频时，错句和收藏词句所在的句子会保留下来（文字和几秒钟的原声片段，存在 `library/kept/`），照样能重练和复习
- 侧边栏「最近在看」显示最近 3 个视频和播放进度，点一下从上次的位置继续（记录在 `library/recent.json`）

## 设置

设置分五页，左边是目录，每页开头一句话说明它管什么：

- **学习**：水平、目标和每天学多少的摘要，在「我的目标」里改
- **模型与服务**：服务商与密钥（翻译、AI 批改、写文章都用选中的服务商）、语音识别、朗读声音。每个服务商的 API Key 只在「服务商与密钥」里填一次，云端语音识别也从这里取
- **播放**：倍速、中文字幕、高亮、短语对照释义、逐句暂停等
- **外观与语言**：母语、主题、字幕字号
- **数据**：视频下载画质、存储空间、备份、手机访问

以前的 `/settings/backup` 等地址和 `/level` 都会自动跳到新位置，书签不会失效。

改了水平或目标之后，视频和文章里标出的难词立即跟着变，不用重新导入。

## 语音识别、手机访问和备份

**语音识别**（设置 → 模型与服务）：视频没有字幕时，以及口语练习的录音，都用这里选的方式转成英文。本地模型可选基础 / 小 / 中 / 大；选「自动」时，Apple 芯片的 Mac 和有 NVIDIA 显卡的电脑用大模型（约 1.6 GB），其他电脑用小模型。为了不让第一次导入等 1.6 GB 下载，「自动」会先用小模型（约 0.5 GB）开始识别，大模型在后台下载，下载好后新导入的视频自动换上。也可以选「云端」：OpenAI（whisper-1）、Groq（whisper-large-v3-turbo）或其他支持逐词时间的 OpenAI 兼容接口，密钥用「服务商与密钥」里已经填好的那个（没填时点一下就跳过去填，只保存密钥、不改翻译用的服务商），没有显卡的电脑也能用大模型的准确率；音频压缩成小的 MP3 分段上传，连不上时自动改用本地模型。

**手机访问**（设置 → 数据）：打开后重启一次，同一个 Wi-Fi 里的手机扫二维码就能在浏览器里复习单词、听写、读文章。二维码里带访问密钥，没扫过的设备打不开；API Key、备份和这些设置只能在电脑上改。手机浏览器只允许 HTTPS 页面录音，所以口语练习请在电脑上做。开着 VPN / 代理时也会选出真正的 Wi-Fi 地址。

**备份**（设置 → 数据）：「下载备份」导出一个 zip（收藏、复习记录、错句本、听写成绩、文章、口语和作文记录、删除视频后保留的原句片段；可选包含视频；不含 API Key）。「从备份恢复」会先把要被替换的文件另存到 `data/backups/`。还可以选一个同步到网盘的文件夹（iCloud Drive、OneDrive、Dropbox、坚果云等），电脑开着 IELTS Study 时每天自动备份一次，保留最近几份。

## 调整

在 设置 → 模型与服务 → 服务商与密钥 选择 OpenAI 兼容 API，填写服务地址、模型名称及服务商需要的密钥。测试连接后保存，新导入或重新处理的视频会使用所选翻译方式。API 仅接收字幕文字，密钥保存在本机 `data/settings.json`。

API 请求遇到限流、超时或返回格式不对时会自动重试 2 次；仍然失败的那一段改用本地翻译。如果密钥、地址或模型名称有误，整段视频改用本地翻译。播放器顶部会显示这次用的是哪种翻译。

环境变量：

- `IELTS_WHISPER=mlx-community/whisper-small.en-mlx`：直接指定本地识别模型（优先于设置里的选择）
- `IELTS_PORT=8765`：端口

想加自己的短语：编辑 `src/ielts_study/phrases_curated.json`，格式 `{"en": "...", "zh": "...", "note": "..."}`，英文第一个词写原形（如 `take care of`）。

YouTube 下载失败时，先更新 yt-dlp：

```bash
uv lock --upgrade-package yt-dlp && uv sync
```

## 文件位置

- `library/<视频ID>/`：视频和 `data.json`（字幕、翻译、标注）
- `library/words.json`：所有词的唯一记录（状态：学习中 / 已掌握，来源，复习进度）；`library/sentences.json`：句子收藏。旧版的 `vocab.json`、`profile.json` 里的认识词和 `wordbook.json` 在启动时自动合并进来，旧文件改名为 `.bak` 并打包成 `backup-before-words-merge.zip`
- `library/wordbook.json`：选的词书；`library/examples/<语言>.json`：API 写的例句缓存
- `library/activity.json`：每天的精听、精读时间和听写、复习数量
- `library/language.json`：母语（以及单独设的界面语言）
- `library/meanings/<语言>.json`：翻成母语的单词释义缓存
- `library/profile.json`：「我的目标」的全部数据：现在的水平、目标分数、考试日期、阶段（自动或手动）、手动改过的每日配额、测试记录
- `articles/<文章ID>/data.json`：文章精读的句子、翻译和标注
- `library/speaking/`：口语练习的录音和评分记录；`library/writing/`：批改过的作文
- `data/ecdict.csv`、`data/ecdict.db`：离线词典
- `data/settings.json`、`data/asr.json`、`data/network.json`、`data/backup.json`：API、语音识别、手机访问和自动备份的设置（含密钥，不会放进备份）

## 开发

```bash
uv run pytest
```

测试覆盖短语对齐、翻译设置校验、文章拆句，以及「只接受本机页面的写请求」和版本检查。改了 Python 代码后，后台服务会提示重启：页面顶部出现「立即重启」，或者再运行一次 `uv run ielts-study`、双击桌面图标，都会自动换成最新代码。

## 已知局限

- 离线翻译质量不如大模型，偶尔会直译或误译（如 trunks → 树干）。可在播放器里按 C 隐藏中文，先自己理解。
- 重点检测按规则进行，不理解上下文：同一个短语在不同语境下给出的是同一条释义。
- 下载视频请遵守各平台的使用条款，仅用于个人学习。
