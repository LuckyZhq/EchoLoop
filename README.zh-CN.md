EchoLoop 是一款在本机运行的英语学习与六级备考工作台，支持 macOS、Windows 和 Linux。默认针对**大学英语六级（CET-6）**优化，并可随时切换四级或雅思轨道。贴入 YouTube、Bilibili、TED 或播客链接，就可以逐句精听、查生词，把想掌握的词留到之后复习。

## 主要功能

- **视频精听**。看双语字幕和逐词高亮，优先标出六级大纲核心词与重点短语。支持单句循环、逐句暂停、调速和点词查义。配置兼容的翻译 API 后，可在英文短语下方显示对应译文。
- **听写与错句本**。听一句、打一句，提交后逐词比对。相似度低于 90% 的句子会进错句本，可以听原声再练。删除视频时，应用可以保留错句和收藏单词的原句片段。
- **文章精读**。内置四级、六级（8 篇精选短文）及雅思 5.5、6.5、7+ 分级文章。可粘贴自己的文章，逐句看译文、点词查义，收藏有用的句子。
- **单词与句子**。通过「今日复习」「词书」「我的生词」「句子收藏」管理学习内容，内置大学英语六级、四级、高频核心词、考研、雅思、托福词书。间隔复习把词带回原句做填空，有可用原声时也能回听。在任一页面标记「认识」，其他页面也会跳过这个词。
- **口语练习**。录音跟读原句，或按**六级口语（CET-SET6）**自我介绍、1 分钟准备 + 1.5 分钟话题陈述与深入问答模考（同时保留雅思 Part 1–3 模考）。可查看识别文本、语速、停顿和口头禅，配置 API 后还能获得按六级口语 15 分制 / A+–D 等级或雅思标准给出的练习反馈。
- **写作与段落翻译**。练习**六级作文**（150–200 词、30 分钟计时）与**六级段落汉译英**，以及雅思图表、书信和议论文。支持实时字数统计和草稿自动保存；配置 API 后可获得按六级 15 分制（折合 106.5 分制）的分项反馈、逐句纠错、地道表达建议和 14 分参考范文/译文。
- **备考目标与进度**。用 5 分钟词汇测试粗估当前词汇量与六级分数（710 分制），也可手动切换备考方向与分数。填写目标分数和考试日期后，可以调整每日任务、查看连续学习天数和进度。

## 本地工具与可选服务

- **翻译、识别与朗读**。提供 ECDICT 离线词典、Argos 本地翻译（可能译错的句子旁会标一个“?”）、Whisper 本地语音识别和 Kokoro 朗读（默认美式发音适配四六级，可切换英式或澳式）。部分资源在首次使用时下载，也可配置兼容的云端翻译或语音识别接口。
- **界面与译文语言**。支持 16 种语言，界面语言可以和译文、释义语言分别设置。
- **手机访问**。开启后，同一 Wi-Fi 下扫码即可在手机上复习单词、听写或阅读。
- **备份与恢复**。学习记录可导出为 ZIP，视频可选。可以从 ZIP 恢复（向下兼容原 IELTS Study 备份），也能每天自动备份到指定文件夹。

本地学习功能无需 EchoLoop 账号。启用云端功能时，处理所需的文字或音频会发送给你配置的服务商。也可以导入 Apple 播客、小宇宙的单集链接和音频直链。

## 快速开始

安装 Git 和 [uv](https://docs.astral.sh/uv/getting-started/installation/) 后，在终端或 PowerShell 中运行：

```bash
git clone https://github.com/LuckyZhq/EchoLoop.git
cd EchoLoop
uv run echoloop
```

浏览器打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。第一次启动会安装依赖并下载离线词典，请预留几分钟。
